# My Travel Planner

A personal travel organizer: a day-by-day timeline of flights, trains, hotels, meetings and transfers, with a calendar, contacts and booking documents.

- **App:** https://kian-gerowgan.github.io/My-Travel-Planner/
- **Data:** stored in the owner's Google Drive (`My Travel Planner` folder), never in this repository.

## Development

```bash
npm install
npm run dev      # http://localhost:5180/My-Travel-Planner/
npm run build
```

Every push to `main` is built and published to GitHub Pages by `.github/workflows/deploy.yml`.

`prototype/` holds the original single-file prototype for reference.
